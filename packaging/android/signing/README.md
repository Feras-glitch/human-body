# مفتاح توقيع أندرويد

**لا يُحفظ المفتاح ولا كلمة سره في هذا المستودع.** من يملكهما يستطيع توقيع تحديث مزيف يُثبَّت فوق نسخة الأطفال.

- المفتاح الحالي (منذ 1.1.7): `humanbody-2026.jks`، الاسم المستعار `humanbody`، RSA 3072، صالح حتى 2126.
- بصمة الشهادة SHA-256: `D9:97:7A:32:D4:7F:08:AB:3B:20:18:91:63:9B:D1:B0:B0:BB:4F:FB:09:4C:7A:02:07:8A:27:AC:4B:81:2C:15`
- مكانه عند البناء: `~/.humanbody/humanbody-2026.jks` وبجانبه `keystore.properties`، أو المتغيّران `HB_KEYSTORE` و`HB_KEYSTORE_PASS`.
- احفظ نسختين منه في مكانين مختلفين (مثلاً: مدير كلمات سر + قرص خارجي). ضياعه يعني أن الأجهزة لن تقبل أي تحديث، وتلزم إعادة التثبيت.

المفتاح السابق (بصمته تبدأ `3B:CF:25`) كان محفوظاً في المستودع، فاستُبدل. الأجهزة التي ثبّتت 1.1.x تحتاج مرة واحدة: نسخة احتياطية من شاشة ولي الأمر ← حذف التطبيق ← تثبيت 1.1.7 ← استعادة النسخة.

**تنبيه لأندرويد 7–9:** حتى 1.2.0 كانت النسخة تُحفظ في مجلد التطبيق الخاص (`Android/data/com.feras.humanbody/files/Download`)، وهو يُمحى مع حذف التطبيق. انسخ الملف من ذلك المجلد إلى مكان آخر (بمدير الملفات أو إلى حاسوب) قبل حذف التطبيق. ومن 1.3.0 يُختار مكان الحفظ بنافذة النظام، فيبقى الملف بعد الحذف.

## مفتاح البناء الآلي على GitHub (منذ 28 نوفمبر 2026، بقرار صاحب المشروع)
- النسخ المبنية في GitHub Actions (`.github/workflows/build-apps.yml`) توقَّع بمفتاح جديد: الاسم المستعار `humanbody`، RSA 4096، صالح 100 سنة.
- المفتاح محفوظ **مشفّراً** (AES-256، PBKDF2 بـ200 ألف دورة) في `ci/release.jks.enc`، وكلمة سرّه سرّ في إعدادات المستودع باسم `HB_KEYSTORE_PASSWORD`. بلا الكلمة لا يُفكّ الملف.
- بصمة الشهادة المعتمدة في `ci/release-cert.sha256`، ويتوقف البناء إن اختلفت.
- **احفظ كلمة السر خارج GitHub في مكانين:** إن ضاعت فلن يُثبَّت تحديث فوق النسخ الموجودة.
- نسخة مثبتة بالمفتاح القديم (`humanbody-2026.jks`) لا تتحدّث بنسخة هذا المفتاح: نسخة احتياطية من شاشة ولي الأمر ← حذف التطبيق ← تثبيت الجديد ← استعادة النسخة.
