# بنية التطبيق التفاعلي وحالته — 25 أكتوبر 2026

## المبدأ (D04 + D26 + D27)
النص العلمي لكل درس في ملف المصدر `lessons/<id>.json` فقط. منه تُولَّد ثلاثة مخرجات: كتاب المعلم، دفتر الطالب، **وشاشة التطبيق**. التطبيق طبقتان:

1. **المولّد** `tools/build-scenes.mjs` + `app/v2/lesson-runtime.js`: يبني من JSON تسلسل المشاهد القياسي لكل درس (غلاف وسؤال الدرس → افتتاح شرعي → جذب لا يُحتسب → شرح مع تعريف كل مفهوم عند أول ذكر → تدريب موزّع → تجربة → تحقق → اكتشف الخطأ → أرقام تدهشك → رسالة من أعضاء جسمي → علماء حضارتنا → كيف عرفنا وحدود النموذج → ختام شرعي → في حياتي → ما لا يعرفه أحد بعد → الدفتر → المسرد بثلاث لغات → الختام). الآية كاملة بخط المصحف مع تظليل، والحديث كاملاً.
2. **طبقة التأليف الخاص** `app/v2/scenes/<id>.js`: لكل درس ملف يعرّف `CUSTOM = { replace, before, after, drop }` يستبدل أي مشهد مولَّد بمشهد تفاعلي أو يضيف ألعاباً بينها. بطاقات المفاهيم تنتقل تلقائياً مع أي مشهد مُستبدَل أو محذوف فلا يضيع تعريف.

المحرك المشترك: `engine.js` (الملف الشخصي، التذكير/التأنيث، الصوت، الأسئلة، التقدم) و`engine.css` (ألوان صريحة لكل نص وزر؛ لا يتأثر بالوضع الداكن للجهاز).

**الشرح والتغذية الراجعة**: لكل بند اختيار وترتيب حقل `explanation` (لماذا الصواب صواب، مما في الدرس نفسه) يظهر بعد الإجابة أو بعد «أرني الصواب»، وفي كتاب المعلم، وفي قائمة التسجيل (`item.<id>.why`). و47 بنداً موسوماً بتصور خاطئ لها `feedback_by_option`: ردّ على الخيار الذي يحمل التصور، من سجل التصورات. الحقلان موصوفان في `schema/lesson.schema.json`.

**صيغ المؤنث**: العلامة تغطي الكلمة كلها حين يتغير جسمها: `{تراه|ترينه}`، `{تعلمته|تعلمتِه}`، `{هادئاً|هادئةً}` — لا `تراه{|ينه}` (كانت تعطي البنت «تراهينه»). اختبار في `tests/review-fixes.cjs` يرفض النمط القديم.

**الوسائط على جهاز بطيء**: `Atlas.ready` ينتظر تحميل وسائط الطفل حتى 15 ثانية؛ وما لم يُحمَّل بعدها يُحمَّل عند الحاجة (`Atlas.storage.load`)، ومشهد الرسم لا يقبل خطاً فوق رسم لم يظهر بعد. والنسخة الاحتياطية تنبّه إن تعذّرت قراءة تسجيل أو رسم بدل أن تبدو كاملة. وإن تعذّر المخزن وامتلأ الجهاز يبقى التسجيل السابق كما هو.

**نسيت الرمز**: يمسح عدّاد المحاولات، ويظهر تاريخه لولي الأمر في شاشته، ويوسم كل اعتماد بعده. السؤال الحسابي يتغيّر بعد كل جواب خاطئ، ومعه انتظار يتضاعف (10 ثوانٍ حتى 10 دقائق) محفوظ بعد إعادة التحميل. وشاشة ولي الأمر تُقفل حين تُغادَر (`pagehide`) لا بعد ربع ساعة.

**الاستئناف**: يُحفظ موضع الدرس بمعرّف المشهد (`sceneId`) لا برقمه وحده، فتحديثٌ يغيّر عدد المشاهد لا يفتح الدرس على مشهد آخر؛ ولا يُستأنف على مشهد الختام ما لم يكتمل الدرس.

## استوديو جسم الإنسان (16–19 نوفمبر 2026، الوثيقة 24)
تطبيق أندرويد مستقل للفريق (`studio/`، `com.feras.humanbody.studio`) بستة أدوار:
- **المعلق الصوتي:** تسجيل كل جملة في سياقها ← «حزمة صوت» يستوردها ولي الأمر (`VoicePack` في `state.js`) أو تُدمج (`tools/import-voice-pack.mjs`).
- **المحرر، والمراجع العلمي، والمراجع الشرعي، والمعلم:** تعديلات (الآيات والأحاديث مقفلة) ومراجعات وملاحظات ← «حزمة تعديلات» ← `tools/import-change-pack.mjs` (يطبّق ما يطابق أصله ويفحص كل درس تغيّر ويردّه إن فشل؛ المراجعات في `reviews/`؛ لا يغيّر `reviewed`).
- **المطوّر:** لوحة حالة الدروس.
- **حزمة التحديث الموقّعة:** `tools/make-update-pack.mjs` ← ولي الأمر يستوردها في أندرويد (`UpdatePack.java`) وويندوز (`packaging/desktop/update.js`)؛ تُرفض غير الموقّعة والمعدّلة وما صُنع لنسخة أخرى.

## الاختبار الآلي
`node tools/check-terms.js`: فحص «لا مصطلح قبل تعريفه» — يعرض كل درس مشهداً مشهداً ويبلّغ عن أي مفهوم ظهر قبل بطاقته. ومنذ 25 أكتوبر صار التعريف **ديناميكياً**: أي مفهوم من مفاهيم الدرس يظهر نصه في مشهد (بما في ذلك المشاهد الخاصة) تُلحق بطاقته بذلك المشهد تلقائياً عند أول ذكر، ولا تتكرر بعده؛ وما لم يُذكر في أي مشهد يُعرض في «كلمات مهمة» قبل المسرد. حدّ الفحص: النص الذي يظهر بعد لمسة (كاسم عظم يُكشف باللمس) لا يُحتسب ذكراً.
`node tools/walk-gen.js <ids>`: يمشي في كل درس بالولد والبنت، يتفاعل مع كل مشهد حتى النهاية، ويبلّغ عن أي خطأ أو تسريب في صيغ التذكير/التأنيث. الحالة: الدروس الواحد والعشرون (U01–U06) تمرّ كاملة. المشي يستعمل `dispatchEvent` للمناطق المتراكبة (`.hot`) ومعالجاً عاماً للمطابقة الثنائية (`[data-s]→[data-j]`، `[data-o]→[data-c]`)؛ `STACK=1` يطبع موضع الخطأ.

## الأوامر
```
node tools/validate.mjs lessons/*.json   # صحة المصدر (بما فيه القرآن والحديث)
node tools/build-scenes.mjs              # صفحات الدروس + صفحات الوحدات + بيانات المراجعة
node tools/inject-quran.mjs              # حقن نص المصحف في المحرك
node tools/build-home.mjs                # الصفحة الرئيسية
node tools/walk-gen.js U02.L01 ...       # الاختبار الآلي (أضف --tests لصفحات الاختبار، و--level=B)
node tools/check-assessment.mjs          # انحيازات بنك الأسئلة (--cues-report: الدليل الشكلي في الخيارات)
npm run build                            # كل ما سبق من البناء + صفحة الرخص + build-info
node tools/build-studio.mjs              # بيانات الاستوديو (studio/data.js)
node tools/import-voice-pack.mjs <zip>   # دمج حزمة صوت
node tools/import-change-pack.mjs <json> [--apply]  # دمج حزمة تعديلات ومراجعات
node tools/make-update-pack.mjs --base <إيداع>       # حزمة تحديث موقّعة (HB_UPDATE_KEY)
bash packaging/build-studio-android.sh   # APK الاستوديو
node tools/check-books.mjs               # الكتب المطبوعة من المحتوى الحالي؟
node tools/audio-status.mjs              # ما سُجّل بشرياً وما ينقص
bash tools/release.sh draft|release      # الفحوص كلها ثم الحزم
```

## ما ينقص
- (صور المشاهد مكتملة للوحدات الست: 236 صورة بأسماء الخانات (عدا صور U01 الأقدم بأسماء خاصة)؛ المصادر المتجهية والبرومبتات في `art-sources/`.)
- التسجيل الصوتي البشري بعد اعتماد النصوص ميدانياً (D24)، بالاستوديو. الوصل جاهز منذ 1.3.0، والقوائم تغطي 97% من نصوص الدروس و100% من الاختبارات؛ نحو 5,000 نص وقرابة 74 ألف كلمة بالصيغتين (docs/04).
- مراجعة المراجع العلمي للخيارات المعاد صياغتها (الوثيقة 21) مع بقية المحتوى.
- المراجعة الشرعية والعلمية البشرية (الوثيقتان 07 و08).
- القرارات التي تنتظر صاحب المشروع: الوثيقة 25.
