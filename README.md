# «رحلة داخل جسمي»: منهاج جسم الإنسان للأطفال 8–12 — مستودع المصدر الواحد

*علمٌ يُنتفع به · تعلّم · افهم · طبّق · انشر*

منهاج علوم عربي عن جسم الإنسان: **كتاب معلم + تطبيق تعلّم ذاتي تفاعلي بتقييم حقيقي + دفاتر الطالب/الطالبة**، كلها تُولَّد من ملف مصدر واحد لكل درس (`lessons/U##.L##.json`).
مصطلحات بثلاث لغات (العربية/الإنجليزية/الصينية + بينيين)، مخاطبة بالتذكير والتأنيث، طبقة قيم إسلامية بنصوص موثقة (مصحف المدينة، حفص؛ أحاديث بمتونها الكاملة وأحكامها)، وسجل «علماء حضارتنا» بما فعلوا وما لم يفعلوا.

## التشغيل
```bash
node tools/validate.mjs lessons/U06.L01.json      # فحص المصدر (القرآن والحديث والمصادر) — أخطاء = لا نشر
node tools/generate.mjs lessons/U06.L01.json      # كتاب المعلم ودفتر الطالب/الطالبة وقائمة التسجيل → build/
node tools/build-scenes.mjs                       # صفحات الدروس والوحدات وبيانات المراجعة → app/v2/
node tools/inject-quran.mjs                       # حقن نص المصحف في المحرك والصفحات
node tools/build-home.mjs                         # الصفحة الرئيسية
node tools/quran.mjs 7:31 80:24                   # إضافة آيات إلى السجل من بيانات المجمع (لا كتابة يدوية)
node tools/walk-gen.js U06.L01 U06.L02            # الفحص الآلي: يمشي في كل درس ولداً وبنتاً حتى النهاية
node tools/check-terms.js U06.L01                 # فحص «لا مصطلح قبل تعريفه»
```
لا يُكتب نص في `build/` أو في صفحات `app/v2/*.html` مباشرة؛ كل تعديل في `lessons/` (المحتوى) أو `app/v2/scenes/` (التفاعل) ثم يُعاد التوليد.

## نسخ ويندوز وأندرويد
التطبيق يعمل بلا إنترنت (الخطوط محلية). يُغلَّف لويندوز (Electron: مُثبِّت ونسخة محمولة) ولأندرويد (APK موقّع) من لينكس مباشرة: `packaging/build-windows.sh` و`packaging/build-android.sh`. التفاصيل والأدوات ومفتاح التوقيع في `packaging/README.md`.

## قبل أي نشر عام
1. مراجعة علمية بشرية (docs/08)، ومراجعة شرعية لكل نص `reviewed:false` (docs/07)، ومراجعة تاريخية لسجل العلماء.
2. استكمال كل مصدر موسوم «يُستكمل بمرجع مؤسسي» أو «يُراجع الرابط» في `sources`.
3. تجربة ميدانية بورقة docs/05 ثم التسجيل الصوتي بدليل docs/04.
