# المصادر والرخص

`credits.json` هو المصدر الوحيد لقائمة المصادر؛ منه ومن نصوص الرخص هنا يولّد `tools/build-licenses.mjs` صفحة `app/v2/licenses.html` (ضمن `npm run build`)، فتُحزم نصوص الرخص كاملة مع كل نسخة من التطبيق، وتفتحها «عن التطبيق» في شاشة ولي الأمر وقائمة «مساعدة» في ويندوز.

| الملف | ما هو |
|---|---|
| `KFGQPC-fonts.txt` | رخصة مجمع الملك فهد لخطَّي المصحف (منقولة حرفياً من جدول الأسماء في ملفَّي الخط): الاستعمال والنسخ والتوزيع مجاناً، بلا بيع ولا تعديل |
| `KFGQPC-QCF2.txt` | خطوط صفحات مصحف المدينة، الإصدار الثاني (QPC V2) التي تُرسم بها الآيات: مصدرها، وجدول الأسماء في ملفاتها منقولاً حرفياً (لا نص رخصة فيها)، ومصدر رموز الآيات (مكتبة QUL) |
| `Tanzil.txt` | إشعار حقوق نص Tanzil العثماني 1.1 كما في `quran/tanzil/quran-uthmani.txt`: يُنسخ بلا تعديل، مع ذكر المصدر والإحالة إلى tanzil.net، ويُرفق الإشعار بكل نسخة |
| `OFL-*.txt` | SIL Open Font License 1.1 لخطوط الواجهة (ونسخها أيضاً بجانب الخطوط في `app/v2/fonts/`) |

**ما لم يُحسم بعد:**
- إذن إعادة نشر تلاوة الشيخ المنشاوي (ملفات everyayah.com) داخل التطبيق — مكتوب في الصفحة «قيد التحقق» حتى يتحقق صاحب المشروع منه.
- شروط المجمع لخطوط الصفحات (QPC V2): ملفاتها بلا نص رخصة، وصفحة حقوق المجمع لم تُفتح من بيئة البناء، ومكتبة QUL تقول إنها لا تملك معلومات حقوقها. تُستعمل بشروط خطوط المجمع الأخرى حتى يتحقق صاحب المشروع.

عند إضافة خط أو صورة أو نص من مصدر خارجي: أضفه إلى `credits.json`، وضع نص رخصته هنا إن كانت تشترط إرفاقها، ثم `npm run build`.
