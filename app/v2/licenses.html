المصادر والرخص

يعمل التطبيق بلا إنترنت؛ العناوين أدناه للإحالة إلى المصادر لا روابط تُفتح منه.

  • خط عرض الآيات: مجمع الملك فهد لطباعة المصحف الشريف: خطوط مصحف المدينة النبوية، الإصدار الثاني (QPC V2)، خط لكل صفحة من المصحف فيها آية من المنهاج، ورمز لكل كلمة — من موقع المجمع (qurancomplex.gov.sa/TTF) عبر نسخته على GitHub (mustafa0x/qpc-fonts)، بلا تعديل.
    لا نص رخصة في ملفات الخط، ولا معلومات حقوق لها في مكتبة QUL؛ تُستعمل بشروط خطوط المجمع الأخرى (مجاناً، بلا بيع ولا تعديل)، وتأكيد شروط المجمع لهذه الملفات قيد التحقق من صاحب المشروع — qurancomplex.gov.sa — النص الكامل
  • رموز الآيات في خط الصفحة: Quranic Universal Library (QUL) — Tarteel AI: بيانات «QPC V2 Glyphs – Ayah by Ayah»، بلا تعديل.
    مكتبة QUL: تُراجع شروط كل مورد عند مؤلفه؛ والرموز ترميز خطوط المجمع نفسها — qul.tarteel.ai — النص الكامل
  • النص القرآني الاحتياطي (إن تعذّر خط الصفحة): مجمع الملك فهد لطباعة المصحف الشريف: بيانات KFGQPC Hafs Smart v8 (2022) وخطها HafsSmart_08.ttf، وخط UthmanicHafs — مصحف المدينة النبوية، رواية حفص عن عاصم بالرسم العثماني.
    رخصة المجمع للمستخدم: الاستعمال والنسخ والتوزيع مجاناً، بلا بيع ولا تعديل — qurancomplex.gov.sa — النص الكامل
  • النص القرآني للبحث والاحتياط: مشروع Tanzil — نص Uthmani 1.1.
    Creative Commons Attribution 3.0: يُنسخ كما هو بلا تعديل، مع ذكر المصدر والإحالة إلى tanzil.net — tanzil.net — النص الكامل
  • تلاوة الآيات المرفقة: الشيخ محمد صدّيق المنشاوي (مرتّل)، ملفات آيةً آية من everyayah.com.
    إذن إعادة نشرها داخل التطبيق: قيد التحقق من صاحب المشروع — everyayah.com
  • خط العناوين: Baloo Bhaijaan 2 — The Baloo 2 Project Authors (Ek Type).
    SIL Open Font License 1.1 — النص الكامل
  • خط النص: IBM Plex Sans Arabic — IBM Corp..
    SIL Open Font License 1.1 — النص الكامل
  • الحروف الصينية: Noto Sans SC — Google.
    SIL Open Font License 1.1 — النص الكامل

نصوص الرخص كاملة

KFGQPC-QCF2.txt
KFGQPC Mushaf al-Madinah page fonts, second edition (QPC V2 / QCF2), shipped with the app to draw every verse:
one font per Mushaf page that holds a verse of the curriculum (app/v2/fonts/qcf2/QCF2NNN.ttf, NNN = page number;
the list and SHA-256 of each file are in app/v2/fonts/qcf2/SHA256SUMS.txt). Each word, stop mark and verse number
is one glyph of its page font.

Publisher: King Fahd Glorious Quran Printing Complex (KFGQPC), AlMadinah AlMunawwarah, Kingdom of Saudi Arabia,
published for free download at http://qurancomplex.gov.sa/TTF/ . The files here were copied unmodified from the
GitHub mirror https://github.com/mustafa0x/qpc-fonts (commit 8a4f39d, folder mushaf-v2/).

The font files carry no license text. Their name table, copied verbatim (identical in every page font apart from
the page number NNN):
  ID 0 (copyright):  Test Font, KFGQPC
  ID 1 (family):     QCF2NNN
  ID 2 (subfamily):  Regular
  ID 3 (unique ID):  KFGQPC QCF2NNN
  ID 4 (full name):  QCF2NNN
  ID 5 (version):    KFGQPC TEST
  ID 6 (PostScript): QCF2NNN
  ID 7 (trademark):  Test Font, KFGQPC

The mirror refers to KFGQPC's copyright page (http://dm.qurancomplex.gov.sa/copyright-2/), which could not be
opened from the build environment, and the Quranic Universal Library states that it has no copyright information
for this font. Until KFGQPC's terms for these files are confirmed, they are used on the same terms as KFGQPC's other
fonts (KFGQPC-fonts.txt): free of cost, no sale, no modification.

Glyph codes of each verse (which glyph of the page font draws which word): "QPC V2 Glyphs - Ayah by Ayah" from the
Quranic Universal Library (QUL, https://qul.tarteel.ai, Tarteel AI), kept unmodified in quran/qpc2/.
